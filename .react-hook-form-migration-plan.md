## Guiding Principles

1. **Don't break existing behavior.** Server action signatures stay the same; RHF is a client-side validation layer on top.
2. **Use FormFactory where possible.** It already wires `useForm` + `zodResolver` + `FormProvider`. For simple forms, a lighter wrapper is fine.
3. **Use shadcn/ui form primitives** (`Form`, `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormMessage`) from `src/components/ui/form.tsx`.
4. **Keep server actions unchanged** — they accept `FormData` or typed inputs. RHF's `handleSubmit` passes a plain object; convert to `FormData` inside the handler if the action expects it.
5. **Preserve `use-autosave` pattern** for page/post draft forms; add it to collection entry forms where appropriate.
6. **Use `handleActionResponse()`** for unified server-action error/toast handling.

## Migration Phases

### Phase 1 — Foundation (No UI changes)

**Goal:** Build reusable building blocks so every new form follows the same pattern.

1. **Create `useFormAction` hook** (`src/hooks/use-form-action.ts`)
   - Wraps a server action + `handleActionResponse`
   - Returns `{ submit, isPending, error }`
   - Accepts `onSuccess` callback
   - Handles `FormData` conversion from RHF's object output

2. **Create `FormFactory` improvements** (if needed)
   - Ensure it accepts a `submitAction` prop
   - Ensure `FormField`/`FormItem`/`FormMessage` are used consistently
   - Add `reset` support after successful submit

3. **Create field component wrappers** (thin shadcn wrappers for RHF `Controller`)
   - `TextField`, `TextareaField`, `SelectField`, `CheckboxField`, `SwitchField`, `DateField`, `MediaField`, `RelationField`
   - Each accepts `{ name, label, required, ... }` and uses `useFormField`

**Files to create:**
- `src/hooks/use-form-action.ts`
- `src/components/atoms/forms/rhf/` (field wrappers)

## Technical Patterns

### Pattern A: Fixed-field form (FormFactory)

```tsx
import { FormFactory } from '@/components/atoms/forms/factory';
import { z } from 'zod';

const schema = z.object({
  name: z.string().min(1),
  slug: z.string().min(1).regex(/^[a-z0-9-]+$/),
});

export function CreateCollectionForm() {
  return (
    <FormFactory
      schema={schema}
      defaultValues={{ name: '', slug: '' }}
      action={createCollection}
      onSuccess={data => {
        toast.success('Collection created');
        router.refresh();
      }}
    >
      {({ register, formState: { errors } }) => (
        <>
          <FormField
            name="name"
            render={({ field }) => (
              <FormItem>
                <FormLabel>Name</FormLabel>
                <FormControl {...field} />
                <FormMessage>{errors.name?.message}</FormMessage>
              </FormItem>
            )}
          />
          {/* ... */}
          <Button type="submit">Create</Button>
        </>
      )}
    </FormFactory>
  );
}
```

### Pattern B: Dynamic-field form (useForm + Controller)

For collection entries where field names are `data-{key}`:

```tsx
export function CreateEntryForm({ collectionId, fields }) {
  const form = useForm({
    resolver: zodResolver(entrySchema),
    defaultValues: { slug: '', ...defaultData },
  });

  return (
    <form onSubmit={form.handleSubmit(handleSubmit)}>
      <FormField name="slug" ... />
      {fields.map(f => (
        <Controller
          name={`data-${f.key}`}
          control={form.control}
          render={({ field }) => <Textarea {...field} />}
        />
      ))}
      <Button type="submit">Create entry</Button>
    </form>
  );
}
```

### Pattern C: Server action wrapper

```tsx
// src/hooks/use-form-action.ts
export function useFormAction<TInput, TOutput>(
  action: (input: TInput) => Promise<TOutput | { error: string }>,
  onSuccess: (result: TOutput) => void
) {
  const [isPending, setIsPending] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const submit = async (input: TInput) => {
    setIsPending(true);
    setError(null);
    const result = await action(input);
    setIsPending(false);
    if ('error' in result) {
      setError(result.error);
    } else {
      onSuccess(result);
    }
  };

  return { submit, isPending, error };
}
```

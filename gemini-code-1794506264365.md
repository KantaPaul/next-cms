## Overview
`next-cms` is a pro-grade visual website builder and headless CMS studio. The builder UI prioritizes high information density without visual clutter: the user's own page canvas stays center-stage on a neutral slate-black dot grid, while surrounding sidebars, the floating Island dock, and the Right Inspector recede behind crisp 1px borders.

## Colors
- **Canvas & Surfaces (`#0F1012` → `#16171B` → `#1E2026`):** Use `#0F1012` exclusively for the infinite canvas backdrop and timeline grid. Use `#16171B` for anchored sidebars and top/bottom toolbars, and `#1E2026` for inputs, popovers, and the floating Island dock.
- **Primary (`#3B82F6`):** Reserved strictly for active canvas selection outlines, the Publish CTA, active inspector tabs, and focus rings. Never flood large panels or backgrounds with primary blue.
- **Semantic Accents:** Use `#06B6D4` (cyan) and `#6366F1` (indigo) only for interaction timeline action bars and variable/dynamic-binding badges (`{{api.*}}`, `--cms-var-*`).
- **Status (`#22C55E`, `#F59E0B`, `#EF4444`):** Reserved for Page Audit severity badges, form validation states, and publish status indicators.

## Typography
- **UI Chrome (`Inter`):** Keep inspector labels at `12px` (`label-sm`, weight `500`) and section headers at `11px`–`12px` muted or `14px` semibold (`heading-sm`) so controls scan rapidly.
- **Technical Values (`JetBrains Mono`):** Render all CSS units (`px`, `rem`, `%`), hex codes, class names (`.cms-cls-*`), CSS variable names (`--cms-var-*`), and timeline timestamps (`0.0s`–`2.4s`) in `mono-xs` with tabular numerals.

## Layout
- **4px Base Grid:** All internal panel padding, control gaps, and icon spacing use multiples of `4px` (`4px`, `8px`, `12px`, `16px`).
- **Studio Shell Proportions:** Top bar height `44px`; Left Sidebar (`Pages`, `Layers`, `Assets`, `Variables`) width `240px` with a `44px` anchored icon rail; Right Inspector (`Design`, `Interaction`, `Settings`) width `280px`; collapsible bottom Interaction Timeline Drawer height `220px`–`280px`.
- **Inspector Grid:** Pair numeric inputs in 2-column grids (`8px` gap) inside `12px` padded collapsible sections separated by `1px solid #27272A` dividers.

## Elevation & Depth
- Rely on flat tonal stepping (`#0F1012` → `#16171B` → `#1E2026`) and `1px solid #27272A` borders rather than heavy drop shadows.
- Reserve soft shadows (`0 8px 24px rgba(0, 0, 0, 0.45)`) exclusively for floating overlays: the bottom-center Island dock, context menus, and color/variable pickers.

## Shapes
- **Sharp Tooling Geometry:** Use `6px` (`sm`) for inputs, buttons, and tabs; `8px` (`md`) for cards and modals; `12px` (`lg`) for the floating Island dock; and `4px` (`xs`) for compact class/variable chips. Avoid overly rounded (`16px+`) cards inside the editor chrome.

## Components
- **3-Tab Right Inspector:** Top segmented control (`Design`, `Interaction`, `Settings`), followed by a `ClassSelector` chip bar and `StateDropdown` (`Default`, `Hover`, `Focus`, `Active`).
- **Floating Island Dock:** Centered `16px` above the bottom canvas edge, housing atomic primitive buttons (`Section`, `Container`, `Stack`, `Grid`, `Heading`, `Image`, `Vector`, `Form`) with `28px × 28px` icon hit targets.
- **Layers Tree:** `28px` row height, `12px` indentation per nesting level, left expand chevron, element type icon, editable name, and right-aligned visibility/interaction indicator dots.
- **Variable & Token Table:** Spreadsheet-style rows with drag handle, inline editable token name, `16px` color swatch or numeric input per mode column (`Default`, `Dark`), and an alias link trigger.

## Do's and Don'ts
- **Do** keep canvas artboards unobstructed and reserve bright colors for selection outlines, active states, and audit alerts.
- **Do** show empty states and loading skeletons for Collection/External API bindings in preview panels.
- **Don't** mix marketing-style gradients, oversized padding, or decorative illustrations into the builder chrome.
- **Don't** use `!important`-style visual noise or multiple competing primary CTA buttons in the same panel.

## Responsive Behavior
- On desktop (`>= 1280px`), render Left Sidebar, Center Infinite Canvas, and Right Inspector side-by-side.
- On narrower viewports (`< 1280px`), allow Left Sidebar and Right Inspector to collapse into overlay drawers while keeping the top bar and Island dock accessible.

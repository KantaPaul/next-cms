# Builder Blocks Reference

Every built-in block available in the Meridian visual editor (75 blocks):

- **Hero**: Headline banner with copy and actions (`<section>`)
- **CTA**: Prompt with a call-to-action button (`<section>`)
- **Features**: Grid of features with icons (`<section>`)
- **Stats**: Key numbers with labels (`<section>`)
- **Pricing**: Plans with prices and features (`<section>`)
- **Testimonials**: Customer quotes with names (`<section>`)
- **FAQ**: Questions with expandable answers (`<section>`)
- **LogoCloud**: Row of partner or customer logos (`<section>`)
- **Team**: People with photos and roles (`<section>`)
- **Timeline**: Milestones in order (`<section>`)
- **Columns**: Two to four side-by-side columns (`<div>`)
- **Container**: Flex or grid box for any blocks (`<div>`)
- **Button**: Link styled as a button (`<a>`)
- **Spacer**: Empty vertical space (`<div>`)
- **ImageMorph**: Images that morph on scroll (`<div>`)
- **LightboxImage**: Dynamic lightbox image viewer for popups and drawers (`<figure>`)
- **Slider**: Slides with navigation (`<section>`)
- **Tabs**: Content switched by tabs (`<div>`)
- **Accordion**: Collapsible panels (`<div>`)
- **RichText**: Formatted text and headings (`<div>`)
- **Image**: Single image with alt text (`<figure>`)
- **Gallery**: Grid of images (`<section>`)
- **Video**: Embedded video player (`<figure>`)
- **VideoLibrary**: Browsable list of videos (`<section>`)
- **Embed**: Third-party iframe or embed URL (`<div>`)
- **Map**: Interactive location map (`<div>`)
- **Code**: Code snippet with a copy button (`<pre>`)
- **Audio**: Audio file in a card with a player (`<figure>`)
- **Newsletter**: Email sign-up form (`<section>`)
- **ContactForm**: Form that sends messages (`<form>`)
- **PrivacyRequest**: GDPR data export and erasure request form (`<section>`)
- **CollectionItem**: Field from the current collection item (`<div>`)
- **GlobalRef**: Shared block synced across pages (`<div>`)
- **CollectionBlock**: Reusable block for this post type (`<div>`)
- **LoopGrid**: Repeat a saved Loop Item template over posts or a post type (`<section>`)
- **BlogPosts**: List of recent posts (`<section>`)
- **PostTitle**: Title of the current post (`<h1>`)
- **PostFeaturedImage**: Featured image of the post (`<figure>`)
- **PostMeta**: Author, date, and reading time (`<div>`)
- **PostContent**: Body of the current post (`<article>`)
- **RelatedPosts**: Posts related to this one (`<section>`)
- **AuthorBio**: The post author’s avatar, name, and bio (`<aside>`)
- **AuthorCard**: Author profile card: avatar, job title, bio, website and social links, post count, latest posts and a link to all their posts (`<aside>`)
- **Comments**: Approved visitor comments with one level of replies and a comment form; new comments wait for approval (`<section>`)
- **ShareButtons**: Copy-link and social share buttons (`<div>`)
- **PostNavigation**: Links to the previous and next post (`<nav>`)
- **BookmarkButton**: Lets visitors save the post in their browser (`<div>`)
- **HeaderBar**: Site header with logo and menu (`<header>`)
- **HeaderColumns**: Header split into columns (`<header>`)
- **FooterColumns**: Footer split into columns (`<footer>`)
- **Logo**: Site logo linking home (`<a>`)
- **NavMenu**: Navigation links from a menu (`<nav>`)
- **MobileMenu**: Menu for small screens (`<nav>`)
- **SearchBox**: Site search field (`<form>`)
- **AnnouncementBar**: Thin notice above the header (`<div>`)
- **SocialIcons**: Links to social profiles (`<ul>`)
- **ContactInfo**: Phone, email, and address (`<address>`)
- **Copyright**: Copyright line with year (`<p>`)
- **FooterLinks**: Group of footer links (`<nav>`)
- **LegalLinks**: Privacy, terms, and similar links (`<nav>`)
- **BackToTop**: Button that scrolls to the top (`<button>`)
- **ThemeToggle**: Light and dark mode switch (`<button>`)
- **Bookmarks**: Saved-posts button and drawer (stored in the visitor’s browser) (`<div>`)
- **LanguageSwitcher**: Switch between site languages (`<div>`)
- **Callout**: Highlighted callout box (info, tip, warning, danger) (`<aside>`)
- **Steps**: Numbered vertical step-by-step instructions (`<ol>`)
- **Kbd**: Inline keyboard shortcut keys (`<kbd>`)
- **ApiTable**: Structured prop or API field reference table (`<table>`)
- **BeforeAfter**: Interactive before/after image comparison slider (`<div>`)
- **ReadingProgress**: Fixed top reading progress bar (`<div>`)
- **DocsSidebar**: Collapsible documentation tree navigation (`<aside>`)
- **DocsPager**: Previous and next documentation page links (`<nav>`)
- **DocSearch**: Cmd-K documentation search dialog (`<div>`)
- **PortfolioGrid**: Filterable project grid with discipline chips (`<section>`)
- **ProjectMeta**: Client, year, role, services, and live link sidebar (`<aside>`)
